## 무엇이 다른가요?

단순히 요청을 막는 데 그치지 않고, 광고가 생기는 지점마다 대응합니다.

- **유튜브 광고 원천 차단**
  재생 응답의 광고 데이터를 제거해 광고가 시작되지 않게 합니다. Shorts도 포함됩니다.
- **10만 개 규칙 기반 차단**
  EasyList·EasyPrivacy에 한국 광고 도메인을 더해 차단합니다.
- **페이지 안쪽 광고까지 숨김**
  네트워크로 잡히지 않는 배너·스폰서·팝업·오버레이를 숨깁니다.
- **우회 기법도 무력화**
  "광고 차단기 꺼라"는 경고와 클릭 리다이렉트(popunder)를 막습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 유튜브 광고 | 영상 전·중·Shorts·피드 광고 제거 |
| 사이트 광고 | 도메인 규칙 + 인라인 DOM 숨김 |
| 차단 통계 | 사이트별 누적 차단 수를 뱃지·팝업에 표시 |
| ON/OFF 토글 | 끄면 자동 새로고침 + 아이콘 회색 처리 |
| 우클릭 차단 | 광고 영역 우클릭 → 사이트별 저장 |
| 안티애드블록 | 감지 경고·팝언더 리다이렉트 차단 |

※ 유튜브 스트리밍 지연 방지를 위해 `redirector.googlevideo.com`은 의도적으로 차단에서 제외했습니다.

## 설치 방법

1번부터 순서대로 따라 하면 끝납니다.

**1. 파일 다운로드하고 압축 풀기**

[**youtube-ad-blocker-v3.0.zip 다운로드**](https://github.com/Donian-kor/YouTube-Ad-Blocker/releases/download/v3.0/youtube-ad-blocker-v3.0.zip) → 압축 풀기
압축을 풀면 `manifest.json`이 들어있는 폴더가 나옵니다.

**2. 개발자 모드 켜고 불러오기**

[📷 스샷 3 넣기 — 개발자 모드 켜진 화면]

[📷 스샷 4 넣기 — "압축해제된 확장 프로그램을 로드합니다" 버튼 화면]

크롬 주소창에 `chrome://extensions/` 입력 → 개발자 모드 ON → **압축해제된 확장 프로그램을 로드합니다** 클릭 → 1번에서 푼 폴더 선택

**3. 설치 확인하고 새로고침**

[📷 스샷 5 넣기 — 설치 완료 카드 + 새로고침 버튼 화면]

카드에 새로고침(↻) 버튼이 보이면 성공 — 누른 뒤 유튜브에서 `F5`

## 자주 묻는 질문

**Q. 통계 숫자가 올라가지 않아요.**
A. 개발자 모드로 불러왔는지 확인해 주세요. 통계는 개발자 모드 확장에서만 동작합니다.

**Q. 토글을 껐더니 아이콘이 회색이에요.**
A. OFF 상태임을 알려주는 정상 동작입니다. 다시 켜면 원래 아이콘으로 돌아옵니다.

**Q. 특정 사이트 광고가 그대로 보여요.**
A. 광고 영역을 우클릭 → 「이 요소 차단」을 눌러 주세요. 사이트별로 저장됩니다.

**Q. 그래도 광고가 차단되지 않아요.**
A. 댓글로 **사이트 주소**와 **간단한 증상**(어떤 광고가 남는지)을 적어주시면 확인 후 규칙을 보강하겠습니다.
