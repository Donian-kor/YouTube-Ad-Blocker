네트워크로 잡히지 않는 배너·스폰서·팝업·오버레이를 CSS로 숨깁니다.

우회 기법도 무력화

"광고 차단기 꺼라" 경고와 클릭 리다이렉트(popunder)를 막습니다.

주요 기능

유튜브 광고영상 전·중·Shorts·피드 광고 제거
사이트 광고도메인 규칙 + 인라인 DOM 숨김
차단 통계사이트별 누적 차단 수를 뱃지·팝업에 표시
ON/OFF 토글끄면 자동 새로고침 + 아이콘 회색 처리
우클릭 차단광고 영역 우클릭 → 사이트별 저장
안티애드블록감지 경고·팝언더 리다이렉트 차단
유튜브 스트리밍 지연 방지를 위해 redirector.googlevideo.com은 의도적으로 차단에서 제외했습니다.

설치 방법

1번부터 순서대로 따라 하면 끝납니다.

1 파일 다운로드하고 압축 풀기
youtube-ad-blocker-v3.0.zip 다운로드 → 압축 풀기
압축을 풀면 manifest.json이 들어있는 폴더가 나옵니다. (이 폴더를 선택합니다)
2 개발자 모드 켜고 불러오기
크롬 주소창에 chrome://extensions/ 입력 → 개발자 모드 ON → 압축해제된 확장 프로그램을 로드합니다 클릭 → 1번에서 푼 폴더 선택
3 설치 확인하고 새로고침
카드에 새로고침(↻) 버튼이 보이면 성공 — 누른 뒤 유튜브에서 F5

자주 묻는 질문

통계 숫자가 올라가지 않아요

개발자 모드로 불러왔는지 확인해 주세요. 통계는 개발자 모드 확장에서만 동작합니다.

토글을 껐더니 아이콘이 회색이에요

OFF 상태임을 알려주는 정상 동작입니다. 다시 켜면 원래 아이콘으로 돌아옵니다.

특정 사이트 광고가 그대로 보여요

광고 영역을 우클릭 → 「이 요소 차단」을 눌러 주세요. 사이트별로 저장됩니다.
